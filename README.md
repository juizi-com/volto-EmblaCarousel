# EmblaCarousel

> [!IMPORTANT]
> **This block has moved.** It is now part of [juizi-blocks](https://github.com/juizi-com/juizi-blocks), Juizi's consolidated block set for Plone 6 and Volto, which is actively maintained (currently in alpha). This repository is no longer updated.
>
> In juizi-blocks this block is the **Carousel** block. Content built with this older block is converted automatically when a page loads; see [COMPATIBILITY.md](https://github.com/juizi-com/juizi-blocks/blob/main/COMPATIBILITY.md).

A block that allows the Editor to create a carousel with either manual slides or a search query (through the schema enhancer). Each slide contains a background image, text, a link, and effective date.
